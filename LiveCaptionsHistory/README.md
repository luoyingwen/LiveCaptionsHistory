# 字幕历史

独立的 Windows 语音转文字窗口，保留完整会话并支持上下滚动回看。直接在自己的识别子进程中调用 Windows 安装的 `LiveCaptionsBackend.CaptionBackend` 及其 Speech/ONNX 组件，不启动或读取 `LiveCaptions.exe`，也没有重新实现语音识别引擎。

## 使用

1. 双击本目录的 `字幕历史.lnk`，或运行 `dist\LiveCaptionsHistory.exe`。请保留整个 `dist` 文件夹，包括 `engine` 子目录。
2. 等待显示“已连接本机引擎”，选择本机已安装的中文或英语模型，播放带声音的内容。
3. 向上滚动回看历史。新字幕继续记录，不抢占阅读位置；点击“回到最新”或按 Ctrl+End 恢复跟随。
4. “暂停记录”会停止音频采集并退出识别子进程；继续时新建识别会话，暂停期间不会补录。
5. 可调整字号、置顶、复制全部或导出文本。遇到识别错误可点击“重新连接”，已有历史会保留。

## 精炼模式

点击“精炼模式”或按 **Ctrl+Shift+M**，窗口只显示可滚动的字幕，隐藏标题栏、工具栏、记录信息和底部状态栏。识别和自动保存继续运行。

- **移动**：拖动窗口顶部留白，或按住 **Alt** 拖动字幕区。也可用 **Alt+方向键**，或右键菜单中的“移动窗口”。
- **调整大小**：拖动窗口边缘。默认 640×240，可缩至 280×100；本次运行内记住精炼窗口的位置和尺寸。
- **返回完整界面**：按 **Esc**、再次按 **Ctrl+Shift+M**，或右键选择“返回完整界面”。完整窗口恢复原位置和尺寸。
- **其他操作**：右键可暂停/继续、置顶、回到最新、复制、导出或关闭。普通鼠标拖动仍用于选择文字，滚轮仍用于回看。

切换模式不会清空历史或重启识别。若关闭时保存失败，会自动恢复完整界面，显示错误并保留记录。

每次运行创建独立记录，每 2 秒自动保存到 `%LOCALAPPDATA%\LiveCaptionsHistory\Sessions`。点击“历史文件”查看以前的文本。关闭窗口会保存历史并结束识别进程；主应用意外结束时，识别进程也会自行退出。

关闭时保存与停止识别同时进行，保存成功后窗口即可消失，后台清理由应用继续管理。引擎正常退出等待预算为 1 秒，超时会结束自有识别进程；窗口关闭后应用最多继续等待后台清理 2 秒。保存失败时保留窗口和字幕，可重试关闭、继续记录或导出。界面线程不再同步等待识别进程退出。

采集来源是电脑正在播放的声音，不限于某一个播放器，多个同时发声的程序可能相互干扰。本版不采集麦克风；如果 Windows 后端报告麦克风模式已开启，应用会提示后停止连接，不更改系统设置。语言切换仅作用于本应用当前会话，重开默认读取 Windows 已保存的语言。

实时识别会修订当前句子；最终识别事件使下一句另起一行，不插入空行。关闭或暂停时仍未完成的句子按当前文本保留。不能恢复应用运行前或暂停期间的语音。

## 运行条件和版本兼容

当前交付适配本机 Windows x64 组件：`LiveCaptionsBackendDll.dll` 版本 `2609.28000.400.0`，SHA-256 为 `0c8054bf89fb05742e82f1667a03afc8f1d6f52ec878296df0974f7747c6b4ca`。需要保留 Windows 内置识别 DLL、已安装的语言模型，以及 .NET 8 Windows Desktop Runtime（本机已有）。

这是 Windows 私有 ABI 的本机适配，不是微软承诺兼容的公共 API。应用会在调用前校验后端文件；Windows 更新导致版本不匹配时会提示需要重新适配，而不会继续使用旧虚表偏移调用。其他 Windows 构建和 ARM64 尚未验证。

没有修改、注入或打补丁到系统程序，没有复制 Windows DLL/模型到应用目录，也没有提取模型密钥。应用本身没有配置云识别服务或上传字幕接口；未对 Windows 后端内部遥测做完整网络审计，因此不把这一点表述为经过验证的“零网络流量”。

## 构建

在此目录运行 `build.ps1`，它先执行历史文本测试，再发布完整应用及识别子进程：

```powershell
.\build.ps1
```

源代码结构：

- `MainWindow`：WPF 窗口、滚动回看、复制/导出、自动保存。
- `CaptionAccumulator`：识别增量、最终结果及会话边界。
- `CaptionReader`：子进程管理、JSON 行协议和旧会话事件过滤。
- `..\SpeechBackendHost`：原 Windows 后端的 WinRT 适配和系统音频采集生命周期。
- `..\docs\architecture.md`：原生后端实现及兼容范围。
- `..\LiveCaptionsHistory.Tests`：30 项历史记录测试。
- `..\LiveCaptionsHistory.LifecycleTests`：正常退出、后台不响应和启动中退出的真实子进程/管道测试。

产品运行不需要 REA、Ghidra、Node.js 或原先探针使用的托管 Speech SDK 包。验证记录见 `VERIFICATION.md`；实现说明见 `..\docs\architecture.md`，界面诊断方法见 `..\diagnostics\README.md`。
